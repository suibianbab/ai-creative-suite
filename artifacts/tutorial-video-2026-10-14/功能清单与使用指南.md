# 自然语言图片编辑 · 功能清单与使用指南

> 基于 2026-10-14 对本仓库的实际运行验证（Node 22.22.2 / Next 16.4 dev / PhotoCraft CLI 0.6.0）。
> 配套演示视频见本目录 `tutorial.mp4`。

## 总览：两个演示入口

| 入口 | 地址 | 定位 |
| --- | --- | --- |
| Image Studio 主工作台 | `/image-studio` | ImageDocument 本地原型：非破坏性图层编辑 + 自然语言指令 |
| PhotoCraft 工作台 | `/image-studio/photocraft` | PhotoCraft 0.6.0 商品图精修：选区 → 预览 → 质量核查 → 保存 |

两个入口的自然语言解析都内置**本地规则引擎**（确定性短语匹配），不依赖任何大模型；
主工作台在 Ollama（qwen3:8b，端口 11434）可用时会优先走模型解析，模型不可用自动回退本地规则，
状态栏会显示 `source = 本地规则`。当前机器 Ollama 未运行，全部功能仍可用。

## 一、Image Studio 主工作台（/image-studio）

### 1. 导入商品图
- 点左上「导入商品图」选择文件，支持 PNG / JPEG / WebP，≤25MB、≤25MP。
- 导入后状态栏提示「已导入原图。当前编辑只改变图层构图，不改写原图像素。」——所有编辑均为非破坏性。

### 2. 自然语言指令（一句话 ≤4 个子句，分号/逗号分隔）
在「编辑要求」输入框里写中文指令，点「预览编辑」生成待应用操作，再「应用编辑」生效，「取消」放弃，「↶ 撤销」回退一步。

本地规则已支持的指令（无需 AI）：

| 类别 | 示例 |
| --- | --- |
| 画布比例 | `画布改成方图` / `竖图` / `横图` |
| 背景颜色 | `背景改成白色` / `黑色` / `浅灰色` / `#f5f5f5` |
| 商品位置 | `商品移到左边` / `右边` / `中间` / `顶部` / `底部` |
| 亮度/对比度/饱和度/曝光 | `亮度提高 20；对比度调到 15`（提高/降低/调到 ±数值） |
| 商品改色（需先抠图） | `商品颜色改为红色`（黑/白/红/蓝/绿/黄/粉/#hex） |
| 标题文字 | `添加标题：秋日新品`、`标题改成新品上市` |

视频演示流程：导入帽子图 → `亮度提高 20；添加标题：秋日新品` → 预览/应用 → 撤销。

### 3. 自动抠图（本机，BiRefNet）
- 在图层列表选中原图图层，点「自动抠图（本机）」。
- 使用本机掩码服务（端口 4101，模型 `birefnet-general-lite`），约 10–60 秒，完成后提示「本机蒙版已生成」。
- 有了蒙版才能执行 `商品颜色改为X`（只改商品、不动背景）。视频演示：`商品颜色改为红色`。

## 二、PhotoCraft 工作台（/image-studio/photocraft）

面向「可直接使用的商品图」的精修闭环，示例任务：**把帽沿改成红色，保留标签**。

1. **上传样片**：选择图片后点「在画布中打开」。
2. **解析编辑要求**：输入 `把帽沿改成红色，保留标签` 点「解析编辑要求」，解析结果应显示目标=帽沿、需保护标签。
3. **建立选区**（关键步骤，决定改哪里/护哪里）：
   - 「选区方式」：智能对象（自动掩码）/ 手动；
   - 「选区模式」：范围 / **自由圈选**（在图上沿帽沿画一圈，≥3 个点）/ patch 加 / patch 减 / **保护区域**（框选标签）。
   - 本任务需要：自由圈选帽沿 + 保护区域框住标签。
4. **预览编辑**：经 PhotoCraft CLI（0.6.0，端口 4112）生成结果与 4 项质量检查。
5. **质量核查**：逐项勾选 4 个质量检查框（保护标签、边缘等）。
6. **应用并保存为可直接使用**：保存为项目，状态栏提示「已保存项目…」。

## 三、已知限制与依赖

- 帽沿等强边缘商品的改色预览存在**青色残边**（仓库 CURRENT_STATE.md 已记录，属已知问题）。
- PhotoCraft CLI 限流：20MB / 1 并发 / 120 秒超时；预览生成需要数十秒属正常。
- 主工作台的模型解析需要 Ollama + qwen3:8b；未启动时自动回退本地规则，仅支持上表固定短语。
- 运行环境 bug（dev 服务器 HMR 握手失败导致页面假死）见 `BUGS.md` 第 1 条，与功能代码无关。
