## 链路

浏览器新建（BASE_URL=http://127.0.0.1:3211）→ STEM 分镜「水循环 4 镜头」（[2000,3100,2000,2000]ms → 218 帧 @24fps）→ 保存
→ **镜头 2 换地图模板 + 旁白并发**：编辑卡先改旁白「降水看分布，行程看路线。」再 `.chart-template-select`（optgroup「地图」组）选「中国六分区示意」→ 单次应用（模板 + 旁白一并落库，地图编辑字段随之出现、草稿自动回填模板默认数据）→ `.map-data-input` 改数据「东城,0,0,30/西城,0,1,20/南城,1,0,25」→ 应用 → 保存
→ **镜头 3 换行程模板 + 数据编辑**：选「两城行程」→ 应用（字段出现、回填「北京,240,420…」）→ 改数据「甲,200,400/500,300/丙,800,600」（中间行为裸坐标途经点）→ 应用 → 保存
→ 导出 JSON 结构断言：镜头 2 `componentId="map-grid"` 且 regions 逐项 = 东城(0,0,30)|西城(0,1,20)|南城(1,0,25) 且工作版本旁白 =「降水看分布，行程看路线。」；镜头 3 `componentId="map-journey"` 且 origin=甲(200,400)、waypoints=[{x:500,y:300}]（裸坐标无标签）、destination=丙(800,600)；时长（3100ms）保留不被模板换掉
→ CLI `render-scene` 双画幅出片（无 `--narration`，零计费）
→ **地图帧数值断言（双画幅）**：ffmpeg signalstats YAVG ≥100——帧 80（镜头 2 域 48..121 内 1333ms：enterMs 1200 + 梯次 2×90ms，三块全部到位）；帧 140（镜头 3 域 122..169 内 750ms：行程描画后段 easeOutCubic(750/1600)≈0.83，白底深字）
→ **双跑**：导出件复制重渲 → 双画幅 SHA-256 逐字节一致；跨进程复跑（整轮 e2e 重执行）媒体哈希仍一致
→ 浏览器控制台零 error；`tts-usage.jsonl` 行数不变。
