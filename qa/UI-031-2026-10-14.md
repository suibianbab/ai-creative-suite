# UI-031：云端 PhotoCraft 编辑任务与质量记录浏览器往返

日期：2026-10-14。环境：本机 Web 3000、API 4000、PhotoCraft 0.6.0 桥接和独立 Worker；本机 Keycloak 开发工作区。素材为仓库帽图样本的独立副本 `.tools/ui031-cloud-hat-20261014.png`，没有修改已有商品云端项目。

1. 在真实浏览器完成开发账户登录，导入帽图，PhotoCraft 官方画布显示 1254×1254、Background 一层。保存本浏览器可编辑项目第 1 版，再保存为独立云端项目 `ui031-cloud-hat-20261014` 第 1 版。
2. 输入“将整张图片顺时针旋转90度”，工作台解析为 PhotoCraft 原生整图方向命令。点击“提交云端编辑任务”，状态先显示 queued，Worker 完成后工作台自动重开云端第 2 版。画布目视可见帽图旋转；当前版本初始为未评级。
3. 选择“需人工精修”，填写“云端方向任务功能验收样本；尚未做商业精修视觉验收。”首次同步返回 HTTP 400：浏览器请求误把本地 `sourceVersion`、`reviewedAt` 字段发送到严格云端 API。修正请求仅发送等级、备注、检查项、标准；新增“重试同步当前质量记录到云端”入口。重试成功，页面显示云端第 2 版的等级与备注，本地记录没有重复创建。
4. 刷新并从云端项目列表重开，发现云端区域评级正确而“当前可编辑版本”仍显示未评级。修正打开云端项目时把服务器审核记录载入当前版本状态和历史。重新登录后再次打开第 2 版，两个区域及本浏览器项目当前项均显示“需人工精修”和相同备注，官方画布仍可打开源项目。

结论：云端方向任务、可编辑版本生成、质量记录同步、刷新和重新登录后的读取在该独立样本上通过。这个用例只证明功能往返；帽图没有经过商业精修视觉验收。其他图像命令仍需逐类迁入 Worker，生产沙箱、配额与独立安全复核仍未完成。
