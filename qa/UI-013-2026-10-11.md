# UI-013 PhotoCraft 局部自然语言编辑回归

日期：2026-10-11。浏览器：本机 Codex in-app browser，`http://localhost:3000/image-studio/photocraft`；服务：PhotoCraft 0.6.0 本机桥接。

## 实测步骤与结果

1. 导入自制 `qa/fixtures/photocraft-hat-teal.png` 并在官方 PhotoCraft 画布打开。
2. 输入“把帽沿改成红色，保留标签”，解析出的计划准确显示帽沿、红色和标签保护框要求。
3. 沿帽沿点击 13 个轮廓点，切到保护模式并依次点击标签框两个角，页面显示青色轮廓和粉色保护框。
4. 点击预览，PhotoCraft 生成红色帽沿；确认后应用，页面显示 1254×1254、2 个图层的结果。本地项目 `photocraft-hat-teal` 第 1 版出现。
5. 刷新，点击该项目，页面确认 `.pcraft` 送入 PhotoCraft 画布。
6. API 实测多项要求“把帽沿改成红色，再去掉标签”返回 HTTP 422；明确句式返回 HTTP 200 和正确 JSON 计划。

结果：功能流程通过。手工套索轮廓在帽沿左侧和下沿留下可见青色细边，当前样片**未通过精品修图视觉质量验收**。后续需改进选区边缘或提供有效的 PhotoCraft 画布精修步骤，再用多类商品回归。本机 Ollama 清单/内存问题由直读 GGUF 的 `llama-server` 路径绕开；浏览器已显示非规则句式“请把帽沿涂成蓝色，保留标签”的正确计划。见 `docs/PHOTOCRAFT_NL_EDITING.md`。

自动回归：`instruction.test.ts` 2/2 通过；`test_local_instruction_bridge.py`、`test_hat_bridge.py`、`test_instruction_model.mjs` 通过；Web TypeScript 和生产构建通过。此次未将一张样片外推为通用商品修图能力。
