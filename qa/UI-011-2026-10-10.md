# UI-011 PhotoCraft 画布与云端原生源回归

日期：2026-10-10。环境：Windows、PhotoCraft 0.6.0 Web/CLI、Next.js 生产构建 `localhost:3000`、NestJS `localhost:4000`、Keycloak 开发 realm、开发 PostgreSQL/RustFS。

## 输入与操作

- 将 `qa/fixtures/photocraft-hat-teal.png` 导入官方 Web 画布；另用 PhotoCraft CLI 生成的两层 `hat-black-v2.pcraft` 测云端原生源。
- Web 画布保存被宿主接收为 `.pcraft`，浏览器项目出现第 1 版；刷新后可直接从本地项目打开。
- 使用开发账户登录；将两层样片上传工作区，刷新，从云端项目重开，再次在官方画布保存并上传。

## 结果

- 导入的图片和图层在官方画布中可见；云端重开后仍有原始像素层和带蒙版的 Hue/Saturation 调整层。
- 云端保存第 1 版、重开、保存第 2 版均在浏览器中确认。过程无需下载后人工重新导入。
- API 的真实 PostgreSQL/RustFS 集成用例 PRJ-003 验证未登录 401、跨租户 403、原图身份固定、过期版本 409、幂等重放返回对应历史版本和源文件字节读取。

## 限制

本地 IndexedDB 按浏览器资料隔离，共享资料的本地项目可见。Web 适配依赖 PhotoCraft 0.6.0 的 DOM/保存行为；生产任务、安全沙箱与上传文件完整格式校验未完成。
