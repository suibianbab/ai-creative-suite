# 云端项目授权边界：复核准备记录

本记录来自本轮实现者自查，不代替 `TASK_RISK_POLICY.md` 要求的独立新上下文复核。当前接口只用于本机开发环境；对外开放状态仍为 **未批准**。

## 已核对的边界

| 边界 | 实现和证据 |
| --- | --- |
| 身份 | API 显式配置 issuer、audience、JWKS 和允许算法；非生产 HTTP JWKS 仅允许本机回环，issuer 也必须与它同源。真实 Keycloak 令牌和公钥验证见 `AUTH-002`、`AUTH-003`。 |
| 工作区授权 | 工作区 ID 只是路由选择器，权限来自每次请求时数据库中的有效用户、组织和工作区成员关系。匿名、跨组织、只读写入与撤销见 `AUTH-001`、`PRJ-003`。 |
| 原件读取 | 请求先验证项目在当前工作区，且 Asset ID 被当前 ImageDocument 引用，才读取并校验 S3 原件字节；下载强制 attachment。见 `PRJ-003`。 |
| 上传 | 守卫在 Multer 前授权，并按 `Content-Length` 拒绝超大请求；单文件 25 MiB、导入最多 50 文件且总原件 100 MiB，接受 PNG/JPEG/WebP 并检查文件头。超大请求提前返回 413，见 `PRJ-003`。 |
| 幂等和版本 | 同一导入/素材请求键重试复用记录；项目保存要求预期版本，旧版本写入返回 409。见 `PRJ-002`、`PRJ-003`。 |
| 对外监听 | API 默认绑定 `127.0.0.1`；容器部署需显式设置 `API_HOST`。 |

## 对外开放前仍需完成

1. 由独立新上下文复核所有认证、租户范围、对象读取和上传错误路径，并复测攻击用例。
2. 运行浏览器 `UI-003`：真实公开客户端授权码交换、导入、增量保存、刷新后重开；目前只验证了登录跳转、PKCE 客户端配置、令牌端点 CORS 和服务端真实令牌访问。
3. 设计生产会话方式与 CSP。开发版令牌在标签的 `sessionStorage`，清除本页会话不结束 Keycloak 会话；尚无刷新令牌和完整退出流程。
4. 加入请求速率及并发上传限制、审计事件、密钥轮换演练、正式成员管理，并确定孤儿对象清理和保留策略。

完整自动回归运行 `node scripts/qa/run-regression.mjs all`；环境失联时报告 `BLOCKED`，恢复后分别重跑集成和 OIDC 分组，不能把阻塞当成通过。
