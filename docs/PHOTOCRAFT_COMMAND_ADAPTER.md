# PhotoCraft 原生命令适配（0.6.0）

Image Studio 继续使用 PhotoCraft 官方 Web 画布和可编辑 .pcraft 源文件。自然语言先形成受约束的编辑计划，选区与操作编译为 PhotoCraft 原生命令，再交给统一执行器；预览确认后才保存新项目版本。平台不实现文字渲染、调色、选区或裁切算法。

本机固定 CLI 提供 commands --json、run、serve、mcp。当前开发桥接仍以单任务 run 执行，每次任务从原图或最新 .pcraft 打开、执行、写入新 .pcraft、渲染预览；画布保存时重新同步原生源。serve 常驻会话与 MCP 可在后续任务调度中评估，尚未宣称已接入生产。

**选区持久化边界（0.6.0）**：Web 画布当前下载 PSD，桥接再规范化为 `.pcraft`。PSD 不保留活动选区，因而在 Web 画布中建选区后点击保存，工作台不能将该活动选区当成已有选区复用；图层和可编辑蒙版仍能保存。原生 `.pcraft` 内的持久化选区则可由 `inspect` 读取并交给 PhotoCraft 原生命令。工作台仅在源文件确实含选区时开放该入口；普通 Web 编辑后的局部操作使用画框、轮廓或 PhotoCraft 蒙版。`IMG-038` 和 `UI-029` 固定复验此边界，未来版本若改变 Web 保存格式再重新验收。

scripts/photocraft/native-command-adapter.mjs 在固定版本上读取命令目录，统一检查命令 ID 并执行。selection-adapter.mjs 单独准备并验证选区，capability-manifest.mjs 为每项效果声明参数检查、所需 PhotoCraft 命令、可编辑结果检查和分组。桥接 /v1/capabilities 从这些已接入能力生成类别；目录列出的 851 项包含依赖上下文或尚未验收的命令，不等于全部开放。参数签名是 PhotoCraft 的说明文本，不是可直接信任的机器 JSON Schema。换色、调整、裁切、污点修复和文字均经过同一执行器。

新增的自然语言文字样例：「在图片上添加文字『SALE』字号72，红色」。用户点击放置点后，桥接调用 PhotoCraft type.create，预览、质量确认、保存和重开仍走同一流程。CLI 验证中文「新品上市」可以显示；文字源重开为 Type 图层。当前仅支持单条文字、黑/白/红、字号 8～160 和点击放置；字体、排版、多段文字、图层样式尚未纳入自然语言能力。

扩展性验证新增「将画布扩展为 12×10 像素」：直接规则形成 canvas-size 计划，经能力配置调用 PhotoCraft image.canvasSize；预览和重新打开 .pcraft 后尺寸一致，原始图片不被覆盖。画布尺寸限 1～8192 像素，居中、白色扩展。当前自然语言仅支持明确的宽×高数值。

第二批能力接入「将图片尺寸调整为 1200×800 像素」和「将整图色阶设为黑场20、白场235、伽马1.2」。前者使用 PhotoCraft `image.imageSize` 的 Lanczos 重采样，限制单边 4096 像素、总计 1600 万像素；后者使用原生 `layer.newAdjustmentLayer.levels` 并保存可编辑调整层。两者都要求明确参数，不把模型给出的任意命令或文件路径传给编辑器。整图色阶当前只支持输入黑/白场和伽马；复杂分通道色阶请在 PhotoCraft 编辑器里调整。

文字样式和投影分别接入 `type.setStyle` 与 `layer.layerStyle.dropShadow`。明确指令示例：「将当前文字设为粗体并加上下划线」「给当前文字图层添加投影，距离8像素，大小10像素，不透明度55%」。作用于 PhotoCraft 当前选中的可编辑图层；文字样式需要 Type 图层，投影需要 Type 或独立 Pixel 图层。仅有一个铺满画布的背景像素层时，投影不可见，因此拒绝执行。更多字体、段落和复杂图层效果继续由 PhotoCraft 原生编辑器处理。

自然语言规划目录在 `apps/web/src/app/image-studio/photocraft/planner-catalog.ts`，由已接入能力生成模型 schema 和提示。模型只选择受限计划；数值和文字从用户原话提取并复核，执行命令仍来自本文件所述的服务端能力配置。`IMG-030` 覆盖不同说法、缺参数和多效果拒绝。增加 PhotoCraft 能力时需同步更新规划目录、服务端配置及两者的回归用例；目录元数据不是直接执行命令的授权。

开放新能力的流程：核对固定版本原生命令与上下文要求 → 给指令计划增加最小参数和确认 UI → 复用统一执行器 → 验证预览与原图保护 → 保存/重开原生源 → 注册固定样图回归。涉及外部文件路径、任意脚本、破坏性命令或生产多租户任务，不从模型输出直接透传到 PhotoCraft。

验证：IMG-025 命令目录/执行器，IMG-026 文字图层，IMG-027 画布扩展，IMG-028 图片尺寸/色阶，IMG-029 文字样式/投影，UI-024 浏览器文字预览；局部换色、矩形提亮、标签保护和黑帽样图在能力拆分后重跑通过。

2026-10-13 新增通用编辑操作：整图顺时针/逆时针旋转 90 度、旋转 180 度、水平/垂直翻转分别映射 PhotoCraft `image.imageRotation.*`；「复制当前图层」「隐藏当前图层」「显示当前图层」映射 `layer.duplicate` 与 `layer.setProps`。工作台对图层操作绑定最后保存的当前图层 ID，并要求只有一个图层被选中；所有操作仍走预览、质量确认、应用和可编辑 `.pcraft` 保存。旋转/翻转不要求画选区，图层操作也不要求选区。两类操作均拒绝不明确或不支持的要求（例如任意角度旋转、删除图层），见 `qa/IMG-036-037-2026-10-13.md`。这些功能只是接入 PhotoCraft 已有命令，不在平台实现几何或图层算法。
