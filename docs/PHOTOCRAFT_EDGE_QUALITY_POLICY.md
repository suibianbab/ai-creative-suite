# PhotoCraft 边缘质量处理与版本复测

日期：2026-10-13。当前集成版本：PhotoCraft 0.6.0。本文记录当前产品的交付边界，不把样片的人工修正参数固化为每张图的规则。

## 通用流程

1. 先用已接入的 PhotoCraft 选区，或现有分割 Provider 给出初始蒙版；结果始终进入 PhotoCraft 原生可编辑图层蒙版，保留原图。
2. 在生成背景或应用局部编辑前，检查主体是否完整、有无误选。用 PhotoCraft 已有的选区增减、边缘精修和蒙版画笔修正明显错误；不要为单张图新增专用抠图算法。
3. 在原尺寸下，分别用浅色、深色和目标背景检查轮廓、细毛、半透明区域及旧背景残色。换背景还要检查投影和主体与场景的光照关系；局部换色要检查目标内部是否完整变色、相邻区域是否污染。
4. 记录结果的实际等级：`可直接使用`、`可使用但有轻微边缘瑕疵`、`需人工精修`、`不适合该用途`。分割或图层结构测试通过不等于视觉质量通过。通用流程处理到哪一级，就只按该级别展示和交付；人工可以继续在 PhotoCraft 蒙版和图层中处理残留。
5. 不以大范围羽化或统一扩展值掩盖漏选、残色；若修正导致主体缺失、明显光晕或邻近区域污染，保留原图与可编辑源，标记 `需人工精修` 或 `不适合该用途`。

PhotoCraft 官方说明提供 Object/Subject Selection、Select and Mask、边缘修改和图层蒙版能力：[README](https://github.com/storytold/photocraft/blob/main/README.md)。其上游能力会变化，不能将当前 `main` 的功能视为固定 0.6.0 已有的功能。项目已经在 0.6.0 测过 `select.refineEdge`；猫毛效果未达标，见 `docs/PHOTOCRAFT_SELECTION_REFINEMENT.md`。当前换背景桥接在主体预览中使用选区、增减套索和蒙版画笔，未默认调用边缘颜色净化或能保证细毛的自动操作。

## PhotoCraft 社区版本升级门槛

1. 保持当前 0.6.0 基线不变，在隔离环境安装候选版本；记录版本、命令清单和可用的 Select and Mask / Refine Hair / 边缘残色处理能力。只采用已验证的命令和行为。
2. 重放 `qa/registry.json` 中 `IMG-035`、`UI-027`、`UI-028` 及相关猫耳用例；使用同一原图、同一背景、同一预览尺寸，对照上述基线，保存 PNG 与可编辑 `.pcraft`。
3. 逐项记录改善、退化和剩余人工工作量。仅当真实样本的视觉结果及保存重开均通过，才调整默认流程和质量等级；保留旧基线供回归。
4. 升级仍无解时继续保留人工精修入口和缺陷记录，不在平台重建 PhotoCraft 的选区引擎。
