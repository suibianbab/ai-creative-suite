# PhotoCraft 桥接任务边界

2026-10-11；本机开发桥接，固定 PhotoCraft CLI 0.6.0。

桥接只绑定 `127.0.0.1:4112`，限制允许的浏览器 Origin、请求文件大小与编辑命令参数。每次任务使用随机 UUID 独立目录；执行命令固定为官方 CLI，参数以数组传入，不经 shell。服务启动时检查 CLI 的实际 `--version` 与固定版本一致；浏览器检查 `/health` 的引擎及版本。当前最多接受一个并发 POST，忙时返回 429 和 `Retry-After: 3`；CLI 单命令 120 秒超时。失败后释放执行名额，下一次有效任务可以运行。`IMG-017` 覆盖版本状态、并发拒绝、无效输入后恢复；`IMG-015` 覆盖 Provider 蒙版进入原生可编辑源。

这仍是个人工作站的开发桥接。它没有服务端用户身份、租户范围、持久任务队列、进程级沙箱、任务审计或配额。它不应对公网开放。云端项目 API 现新增整图方向任务切片：五种固定 PhotoCraft 命令可以经工作区授权提交，Worker 按不可变源版本与资产 ID 执行，保存新的 `.pcraft` 版本，暴露任务状态，支持幂等和有限重试。云端质量分级另以追加式事件按版本保存审核人、检查项和人工说明。`IMG-039` 覆盖隔离数据环境中的接口和真实 CLI 执行。

这不等于 SaaS 生产编辑完成：Worker 目前和 API 运行在同一可信主机，没有独立进程级沙箱、生产配额、部署监控与独立新上下文安全复核；局部和生成式编辑仍使用本机开发桥接。上述门槛完成前不得对公网开放任务执行服务。
