# PhotoCraft context, sequences and local generation (2026-10-13)

## Selected layer and selection

The pinned PhotoCraft 0.6.0 CLI `info --compact` exposes `activeLayer`, `selectedLayers`, layer names/kinds and `selectionBounds`. The workbench reads these through `/v1/inspect` after saving the embedded Web canvas. A local adjustment can use a selection already saved in `.pcraft` (`selectionMethod=existing`). For Type styling and drop shadow the workbench binds the current active layer ID; the bridge rejects a changed layer before editing. The Web bundle still has no upstream live host state API, so the displayed context is the **last saved** PhotoCraft state. Users save the canvas after changing the selected layer or selection.

## Multiple steps

The existing 2–4 step preview pipeline now accepts a text-style plus drop-shadow sequence on one selected layer, and whole-image adjustments followed by Levels or a final geometry change. It uses the PhotoCraft command adapter and intermediate native `.pcraft` files. A partial failure leaves the user's project untouched. One local-selection step is allowed per sequence; later geometry changes must be last. The planner rejects unsupported clauses rather than dropping them.

## Generative local edit

The workbench has a separate development entry for a natural-language local generation request. It now prefers the selection already saved in PhotoCraft; otherwise the user can draw an outline or drag a rectangle. The Web UI produces a transparent edit mask from the selection bounds, and `/api/image-local-edit` calls a configured `LocalImageEditProvider`. The local configuration uses Qwen `qwen-image-2.0-pro` through the server-side `DASHSCOPE_API_KEY`; OpenAI Images Edit remains an alternate adapter. Qwen receives the source image and bounding rectangle coordinates in the prompt, because its image-edit API has no native mask input. The Provider result returns to the PhotoCraft bridge and is placed as an independent layer with a native `layer.layerMask.revealSelection` mask. Source pixels outside the selected mask remain intact. The user can preview, brush the PhotoCraft mask, cancel or apply and save `.pcraft`. Qwen may redraw geometry, text, and material inside the region; this path requires visual review and is not yet a commercial retouching pass.

On 2026-10-13 the configured key returned `Model not exist` for `qwen-image-edit` and `qwen-image-edit-plus`, while `qwen-image-2.0-pro` returned a PNG. The hat-brim spike is `artifacts/qwen-local-edit-spike-2026-10-13.png`; the native PhotoCraft composite and editable source are `artifacts/qwen-local-edit-photocraft-preview-2026-10-13.png` and `.pcraft`. The initial rectangle-masked composite recolored the brim but left a rectangular background seam and a small teal tip. Qwen output was 1024×1024 versus the 1254×1254 source; PhotoCraft scales the generated layer into source dimensions before applying the native mask.

The bridge now accepts an optional outline and uses PhotoCraft `select.lasso`, `select.modify.expand` (one pixel), and `layer.layerMask.revealSelection` for the generated layer. The workbench exposes its existing freehand outline as an explicit mask choice. On the same hat sample, the native contour removed the rectangular seam and recolored the right tip. At four-pixel sample spacing, 8,288 of 8,289 original teal brim samples are red; 22 neutral edge samples differ by more than 20 RGB levels, while a background control pixel and the label/crown remain original. The editable `.pcraft` reopens with two layers and a native mask. This is a sample-specific correction using a manually reviewed contour; it does not establish automatic contour quality for other objects.

A saved PhotoCraft selection now passes through `normalize` into `compose-generated`: the bridge checks `hasSelection`, skips creation of a new selection, places the generated layer and calls `layer.layerMask.revealSelection`. It rejects a request for a saved selection if the source has none. The Web UI uses the saved selection bounds for the provider request and offers an explicit checkbox to ignore it. The generated layer can be reopened and its mask edited. This is `IMG-032`'s current-selection regression.

The bridge mask-stroke route now accepts generated Smart Object layers that have a native mask, as well as adjustment layers. A stand-in regression verifies a white stroke changes the masked generated preview and preserves an editable two-layer source. A broad stroke on the background replacement sample made its shadow edge worse, so this is an editing capability rather than an automatic shadow-quality fix.

## Layered background replacement

The development workbench now offers a separate background task. Qwen is asked for an empty background (the earlier "edit the existing background" prompt retained the hat). The bridge uses a saved PhotoCraft foreground selection when present. Without one, it asks the existing local segmentation provider for a subject mask, loads that mask as a PhotoCraft selection, duplicates the untouched original into a native masked foreground, then places the generated background as an embedded Smart Object below it. The original remains the bottom layer. An optional PhotoCraft Drop Shadow effect on the foreground replaces the original cast shadow; the user can edit or remove it in PhotoCraft. No custom pixel compositor was added.

On the hat sample this removes the broad old gray shadow and preserves the original hat texture and label. PhotoCraft's own `select.subject` selected the cast shadow and produced a hard edge, and `select.colorRange` subtraction made the edge worse; this is why the existing mask provider is the default when no saved selection exists. The fur-cat and multi-object shampoo samples remain visual failures: the fur cutout is too hard and the shampoo cutout includes nearby petals. PhotoCraft `select.refineEdge` did not visibly fix the fur sample. These results are recorded in `qa/IMG-035-2026-10-13.md` and must not be described as commercial-grade automatic replacement.

Foreground selection review now precedes the Qwen call. The workbench can ask PhotoCraft to use its current saved selection, `select.object` within a dragged rectangle, a hand-drawn `select.lasso` outline, or the existing segmentation provider. Native add/subtract lasso patches refine that selection; a neutral native Fill layer makes the mask boundary visible before generating the background. The user can brush the PhotoCraft foreground mask, then generate the background from that corrected native source. The prepared marker is copied across mask-brush revisions and checked before composition, so a stale or unrelated three-layer source cannot be mistaken for a reviewed foreground. On the shampoo sample PhotoCraft object selection plus a single subtract patch removed the wrongly included flower petal; see IMG-035. Fine fur still needs manual work.

Three hat cases were reviewed on 2026-10-13. PhotoCraft native recolor with a contour is the preferred deterministic path and passed the brim quality sample. Qwen label removal using a 15-pixel-feathered PhotoCraft saved selection removed the label and saved as a two-layer editable source; the replacement fabric is smoother than the original and needs manual quality review. Qwen warm-beige background generation followed by PhotoCraft `select.subject` and `select.inverse` preserved the hat, but left old gray shadow regions next to it. Additional `select.object` and `select.colorRange` subtraction attempts still left a visible band. The background case fails visual acceptance and is not presented as a finished background replacement. See `qa/IMG-034-2026-10-13.md` for artifacts and checks.

This route is development-only. It is disabled when the Provider is unconfigured or `NODE_ENV` is not `development`; production needs workspace authorization, queued jobs and Credit Ledger accounting. The key is supplied through the process environment and is not stored in `.env.local`. Generated output with different dimensions is resampled to the source dimensions before placement; review the generated region for shape or alignment changes.
