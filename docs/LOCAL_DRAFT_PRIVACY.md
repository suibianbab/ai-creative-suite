# 本地草稿的浏览器资料边界

Image Studio 当前将本地项目、原图和蒙版以明文存于站点的 IndexedDB。同一浏览器资料里的多个云端账号共用这份数据；清除本页访问令牌或退出 Keycloak 不会删除它。2026-10-10 的双账号浏览器验收确认：无工作区权限的账号无法读取云端项目，却仍能在本地项目列表中打开先前账号的草稿及原图。`UI-004` 因此为失败，不能宣称共享浏览器资料上的本地草稿具备账号隔离。

当前界面会说明这一边界。开发和内部测试使用不同浏览器资料或操作系统账号隔离本地草稿；云端项目由 API 的成员关系授权。此说明不等于安全修复。

对外支持共享设备前，需要选定并验证一个方案：

1. 禁用共享设备上的持久本地草稿，改用云端草稿；保留离线编辑时仅允许临时内存会话。
2. 如必须持久离线保存，设计用户专属的加密密钥、加密原图与文档、登出后销毁内存密钥，以及现有明文 IndexedDB 数据的无损迁移。账号标签或仅隐藏下拉列表不能保护原图字节。

任何迁移必须保留既有草稿，经独立安全复核和 `UI-004` 双账号验证后才能通过此门槛。
