# Task Risk Policy

LOW:
docs, lint, small UI, simple CRUD, tests
→ GPT-5.6 Sol / Low

NORMAL:
standard features, API, Assets, ordinary UI, adapters
→ GPT-5.6 Sol / Medium

HIGH:
ImageDocument, MotionDocument, Scene Editor, Storyboard Editor, render, undo/redo, complex migration
→ GPT-5.6 Sol / High or GPT-6 Astra / Medium-High

CRITICAL:
Credits, Billing, Tenant Isolation, Sandbox, Auth boundaries, Enterprise/AirGap security, Agent Runtime security
→ GPT-6 Astra / High

Critical modules require independent fresh-context review.
